# Problems this testing found and that are fixed in the chart:
#  - the wait-for-db init container looped forever: pg_isready needs -U when the uid has no passwd entry
#  - the frontend's /api proxy failed ("unexpected DNS response"): nginx ignores DNS search domains,
#    so BACKEND_URL now uses the fully qualified service name
#  - two backend replicas starting together raced on "alembic upgrade head": fixed with a Postgres advisory lock

# Troubleshooting labs (troubleshooting/*.yaml) were also run and the documented fixes confirmed:
#  broken-image   -> ErrImagePull, fixed with kubectl set image
#  broken-service -> endpoints <none>, fixed by correcting the selector (endpoints 10.42.0.36:8080)
